# PyRobo

这是交龙视觉部笔试题，你需要遵守以下规范

## 第一题

我们的小车初次抵达这个地图，它现在知道地图是什么样的，现在它想去出口，那么它该如何行动呢？

请你在已知地图和目标点的情况下，为它规划出一条全局路线

## 第二题

太棒了，你已经规划出一条路线了，接下来要让小车尽可能跟随它行动！

请自己规划一个方法，能在xx时间之内开到终点

## 第三题

哎呀，看来小车还没走出去，试试看你的算法能不能适应它吧！

请尝试走出新的地图

## 第四题

不对，小车突然发现自己是有体积的！小车因为违反物理定律被赶了回去，现在你的代码还能让它开到终点吗？

## 第五题

不好，看来有另一辆小车迷路了，你们都是强大的小车，遇见之后撞在一起会直接损坏！

你要想办法让它们不会相撞！

## 第六题

新的地图出现了，但是小明很粗心，不小心在它上面滴了一点墨水，好在墨水不是黑色的，它在地图上不黑不白的，你可以靠自己的雷达探测它的缺口在哪里！

灰色区域是未知区域，它存在一处缺口，你需要自己发现它的位置并规划出一条正确的路径

## 提交方式

请在本文件夹下新建一个git仓库，这些题目每一道的最终版本要求使用`commit message`标识，比如完成第一道题目后的代码版本提交后，
`commit message`一栏写`finish: exercise 1`，事后批卷时，会凭该标识批卷，未按此规范提交的视为白卷
